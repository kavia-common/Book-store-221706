# Quickstart - Book-Store-Frontend

From repo root:
  ./start-frontend.sh

Or manual:
  cd Book-store-221706/bookstorereact
  npm install
  npm run dev

Navigate to:
- http://localhost:3000
- Routes: /, /catalog, /login, /register, /profile, /cart, /checkout

This is a standalone React frontend with mock data and no network requests.
