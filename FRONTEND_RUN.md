# Running Book-Store-Frontend

From repository root:

Option A (script):
  ./start-frontend.sh

Option B (manual):
  cd Book-store-221706/bookstorereact
  npm install
  npm run dev

Acceptance checklist:
- npm install && npm run dev works without errors in Book-Store-Frontend
- Navigating to each route renders without runtime errors
- No network requests are made (mock data only)
- Consistent theme colors applied
