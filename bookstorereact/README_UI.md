# Book Store Frontend (React + Vite + MUI)

- Start dev server: npm start (binds 0.0.0.0:3000)
- Routes:
  - /, /catalog, /login, /register, /profile, /cart, /checkout
- This UI uses mock data and services (no network requests).
- State:
  - CartContext (add/remove/update quantity, subtotal, persisted in localStorage)
  - UserContext (mock login/register and profile update, persisted in localStorage)
- Theme colors:
  - primary #003366, secondary #ec7115, background #f2f2f2, paper #ffffff
