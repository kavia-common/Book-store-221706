# Book-Store-Frontend Container

- Framework: React 18 + Vite + MUI
- Location: Book-store-221706/bookstorereact

Run
  npm install
  npm run dev

Build
  npm run build
  npm run preview

Notes
- Mock-only: No backend/PHP calls
- Theme colors: primary #003366, secondary #ec7115, background #f2f2f2, paper #ffffff
- Routes: /, /catalog, /login, /register, /profile, /cart, /checkout
